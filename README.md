### shipped

**[DayOne](https://github.com/yuvifzy/dayone)** — full-stack productivity app for students. AI-powered study schedule planner via Gemini API. Built with React, Next.js, NeonDB.

**[Natural Shine Salon](https://github.com/yuvifzy/natural-shine-salon)** — client website with booking flow. React + Vite, Framer Motion, Supabase backend.

**[Portfolio](https://yuvraj-mohana.vercel.app/)** — personal site with WebGL + Three.js visuals. Immersive, fast, mine.
